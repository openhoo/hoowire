# Security

Report vulnerabilities using the repository's private vulnerability reporting
feature on GitHub. Avoid including chat content, account data, app bundles,
private keys or certificates. A minimal synthetic fixture and a description of
the affected version are preferred.

The next release is 1.1.0. The project is experimental and has no
guaranteed support or response schedule. New releases are published on this
repository; installed patch recipes do not update themselves over the network.
